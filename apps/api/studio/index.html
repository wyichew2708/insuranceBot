New content

Content written here is not exempt from provenance. Your supporting material is saved to raw/custom/ and becomes the page's authority, so every [src:…] reference resolves to a real file and the reference-integrity gate treats the page like any other. New pages start as draft.

Scan & review

A scan crawls the allowlisted hosts into a staging bundle — never over the live corpus — compiles it, and diffs the result against what is published. It proposes; you dispose. Adopting a suggestion writes a draft, never an approved page.
