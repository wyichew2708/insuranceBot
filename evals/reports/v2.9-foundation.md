The fresh baseline differs from the historical v2.8 published score. This
refactor is compared with the fresh baseline, not treated as an improvement
over a different historical run. No evaluation contracts, gate thresholds,
or known-finding lists were relaxed.

The handler registry names the workflow that actually answered, separates
catalogue metadata from policy evidence, enforces evidence permissions, and
shares the existing per-turn budget and knowledge gate profile. Layer-three
intents share the same knowledge workflow until their execution differs.

Retention keeps the last twenty turns by default and expires idle sessions
after a day, with access-driven cleanup. The later Phase A changes below add typed-state consumers.

## Phase A guidance and Phase B understanding

Phase A's full conversation run also scores **1678/1711**, with **zero gained
and zero lost** relative to the fresh baseline. This is a behaviour-changing
phase, so the byte-identical assertion above applies only to A1 extraction.
Navigation questions are exercised against the real corpus. Promotions use
registry destinations rather than chips promising unverified offer content.
Comparison cells bind to each product/version/tier row, and missing rows are
explicitly unavailable rather than interpreted as excluded cover.

B1 adds typed, persisted self-reported input slots with validation, product
switch isolation, restart recovery and explicit-history overrides. Its country
vocabulary is deliberately limited; vehicle/occupation labels are inputs, not
underwriting classes. B2 adds Malay and Chinese handoffs for the English-only
corpus, output screening, and localised contact labels. It does not translate
policy facts. The field-test suite now has twelve clearly marked authored
language cases in addition to the original field observations.

Full unit run: **1028 passed, 3 skipped**. Ruff lint/format and Mypy pass
(168 source files). Browser verification covers the expandable navigation,
product-question submission, the rendered comparison table and product links.
The corpus's generic extracted benefit labels remain a content-quality
limitation; the comparison handler does not invent better descriptions.

Interaction reporting now measures product selection only on labelled turns,
clarification on all executed turns, dead ends on handoffs (including safety
refusals), and three-chip coverage on product-overview turns. These are
separate measurements, not replacements for the existing pass/fail contracts.

Phase C adapters, verified authentication/ownership, trusted tool-value binding,
Phase D benefit graph, production integration and GPU measurements are still
pending. This report is not a v2.9 release-readiness claim.


Phase B conversation run: **1678/1711**, **zero gained, zero lost** against the
fresh baseline. Field-test run: **112/121**; both original language cases and
all twelve new authored language cases pass. The nine remaining field-test
failures are not waived.
