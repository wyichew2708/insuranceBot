Rules

  • Nodes are generated from the bundle at load time, never written into code.
  • A ✎ node exists only if the page that answers it is approved and effective today.
  • No digits in a node; a number in an answer must bind to a row.
  • ↗ addresses come from the destination registry, never from retrieved text.
  • The map rides on the greeting envelope as a typed map field; a plain client flattens it to chips.
  • Proved by a generated suite that asks every chip and asserts each reply is delivered, plus two report rows: dead-end rate and chip coverage.
